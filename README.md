### Enterprise HR RAG Assistant

Designed and implemented an HR-focused **Retrieval-Augmented Generation (RAG)** assistant for answering employee questions using trusted enterprise HR content.

**Key work:**
- Built document preprocessing, chunking, embeddings, vector search and context-retrieval workflows.
- Integrated **LangChain and OpenAI APIs** for conversational question answering.
- Used **Hugging Face and TensorFlow** for NLP/embedding and classification workflows.

- Implemented response validation based on relevance, context coverage and unsupported-answer checks.
- Analyzed retrieval and generation failures to improve consistency and reduce unsupported responses.
